# PhomiNeuro reproducibility code

This directory contains the code required to construct head models, generate
Monte Carlo targets, adapt the feature encoder, train the neural-field surrogate,
optimize illumination, and reproduce the evaluation.

## Contents

| Directory | Purpose |
|---|---|
| `data_expansion/` | BrainWeb, scatterBrains, SHARM and OASIS-3 ingestion; optical-property mapping; MNI registration; cohort-derived measurements |
| `pmcx_sim/` | Time-resolved MCX simulation and dataset-specific drivers |
| `FM_tune_t4/` | Four-channel VISTA3D adaptation with LoRA, masked reconstruction and STRD bottleneck attention |
| `INR_design/` | Feature-pyramid extraction, buffer construction, PhomiNeuro training, baselines, evaluation and differentiable illumination design |
| `evaluation/` | Shared evaluation helpers |
| `viz/` | Core statistical and cohort figure scripts used for the reported analyses |
| `tests/` | Lightweight consistency tests |

## Data

Restricted data are excluded. Obtain each dataset from its original source:

- SHARM: <https://doi.org/10.6084/m9.figshare.31150387>
- IXI: <https://brain-development.org/ixi-dataset/>
- BrainWeb: <https://brainweb.bic.mni.mcgill.ca>
- scatterBrains: <https://github.com/wumelissa/scatterBrains>
- OASIS-3: <https://www.oasis-brains.org/access> (controlled access; DUA applies)

OASIS-3 data must remain outside the repository and must not be redistributed.

## Configuration

All paths are portable. Generated files default to `reproducibility/work/`.
Override locations with environment variables when working with large datasets:

```bash
export PHOMINEURO_WORK_DIR=/path/to/work
export PHOMINEURO_DATASET_DIR=/path/to/native_head_models
export PHOMINEURO_MNI_DATASET_DIR=/path/to/mni_head_models
export PHOMINEURO_SIM_ROOT=/path/to/mcx_outputs
export INR_PYRDIR=/path/to/feature_pyramids
export PHOMINEURO_INR_CHECKPOINT_DIR=/path/to/inr_checkpoints
export VISTA3D_CKPT=/path/to/vista3d_pretrained_model/model.pt
export SCATTERBRAINS_DIR=/path/to/scatterBrains
export SHARM_DIR=/path/to/SHARM/phantoms
export OASIS_DIR=/path/to/OASIS-3
export GRACE_DIR=/path/to/GRACE
```

Install the Python dependencies with `pip install -r requirements.txt`. The MCX
stage additionally requires the OpenCL `pmcxcl` package and a working OpenCL
runtime. The VISTA3D backbone is obtained separately from
`nvidia/NV-Segment-CTMR`; its license terms continue to apply.

## Pipeline

Run commands from this directory. The principal stages are:

1. Build optical head models with the dataset-specific scripts in
   `data_expansion/`, then register them with `mni_normalize.py`.
2. Generate time-resolved targets with `pmcx_sim/mcx_fluence_simv2.py` or the
   dataset-specific drivers. MCX label volumes must be `uint8` or `int32`.
3. Prepare encoder arrays with `FM_tune_t4/prep_encoder_npy.py` and train the
   LoRA/STRD masked autoencoder with `FM_tune_t4/train_lora_autoencoder.py`.
4. Extract five-scale feature pyramids with
   `INR_design/extract_pyramids_v11.py`.
5. Build training buffers with `INR_design/train_inr_v11.py --save-buffers`,
   followed by `make_pathfeat.py` and `make_entryfeat.py`.
6. Train the final entry-referenced surrogate with `train_inr_v11.py` using the
   configuration recorded below.
7. Evaluate with `eval_bench_pergate.py`, `eval_energy_bycat.py`,
   `eval_censored.py`, and `checkerboard_metric.py`.
8. Run differentiable illumination optimization with `illum_opt_v17.py`.

The final training configuration used three seeds. The command below shows one
seed; repeat it with matching ``--tag`` and ``--seed`` values for seeds 0–2:

```bash
INR_SPLIT=v16_split INR_K=3000 python INR_design/train_inr_v11.py \
  --tag v18hero3_s0 --seed 0 --load-mm /path/to/bufmm_v16 --raw-cpu \
  --src-ref entry --path-suffix _entry --path-trilinear \
  --lambda-pinn 1.0 --lambda-lin 0.3 --lambda-floor 1.0 \
  --hinge-offset 0.5 --lin-clamp 1.0 \
  --dec-sh 2.5 --dec-mid 7.0 --dec-deep 8.0 \
  --shallow-boost 3 --csf-boost 3 --path-feat \
  --num-freq 4 --num-freq-t 3 --drop-optical --drop-light ang \
  --lambda-mono 0 --mono-dec-min 5.0 --mono-center source \
  --mono-rate 0 --lin-dec-max 4.5 --snap-every 60
```

Large intermediate products are not regenerated by the test suite. Before a
production run, execute `python -m compileall .` and run `pytest tests`.
